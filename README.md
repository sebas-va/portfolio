# Portfolio — Sebastian Vargas Huaman

Portfolio profesional inspirado en la atmósfera creativa de Takuya Matsuyama, pero con diseño, ilustración de escritorio y contenido originales.

## Cómo ejecutarlo

No necesitas instalar Node.js ni dependencias.

1. Descomprime la carpeta.
2. Abre `index.html` en Chrome, Firefox o Edge.
3. Alternativamente, en VS Code usa la extensión **Live Server** o ejecuta `python -m http.server 5500` en la carpeta y abre `http://localhost:5500`.

## Incluye

- Diseño responsive (móvil, tablet y escritorio).
- Escena de escritorio 3D simulada mediante CSS con interacción al mover el ratón.
- Tema claro y oscuro con preferencia persistente.
- Secciones Sobre mí, Proyectos, Stack, Trayectoria y Contacto.
- SEO básico, navegación accesible y soporte para movimiento reducido.
- Sin bibliotecas JavaScript obligatorias ni recursos 3D ajenos.

## Personalización

- Textos y proyectos: `index.html`.
- Colores, tipografía y diseño: `styles.css` (`:root` al inicio).
- Interacciones: `script.js`.
- Añade los enlaces definitivos de tus repositorios y CV cuando los publiques.
- Las métricas que aparecen dentro de Pitpta Reserve son **solo ilustrativas** y la interfaz es conceptual.
- Las fuentes de Google Fonts necesitan Internet; si no hay conexión, se utilizan tipografías del sistema.

## Inspiración y atribución

Inspirado en la idea de un portfolio de desarrollador con escena de escritorio de Takuya Matsuyama: https://www.craftz.dog/ — referencia creativa, sin uso del modelo de perro 3D ni de sus activos visuales originales.
